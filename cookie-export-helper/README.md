# 常青圈 Cookie 导出助手（浏览器扩展）

在已登录的 **抖音 / 小红书 / B站** 页面点一下，就把该站点的**全部 Cookie（含 httpOnly）**复制到剪贴板，再粘进常青圈「模型配置 → 编辑配置 → 平台采集」对应框即可。

## 为什么需要扩展而不是书签/油猴脚本？

抖音 `sessionid`、小红书 `web_session`、B站 `SESSDATA` 等关键 Cookie 都是 **httpOnly**，浏览器禁止页面脚本通过 `document.cookie` 读取。本扩展走 `chrome.cookies.getAll` API，不受此限制，能导出完整可用的 Cookie 串。

## 安装（一次性）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 右上角打开 **开发者模式（Developer mode）**。
3. 点 **加载已解压的扩展程序（Load unpacked）**，选择本目录 `cookie-export-helper/`。
4. 扩展安装后，建议点地址栏右侧拼图图标把它**固定**到工具栏。

## 使用

1. 浏览器打开并**登录**目标平台网页版（如 `www.douyin.com`）。
2. 点工具栏里的「VerdaAI Cookie 导出助手」图标，弹窗中点 **复制当前站点 Cookie**。
3. 状态栏显示「已复制 N 个 Cookie（含 M 个 httpOnly）」即成功，下方小字还会提示**最早过期时间**。
4. 回到 VerdaAI 设置页「平台采集」tab，粘进对应框 → 保存。

### 复制前会自动清洗

复制出来的串无需再手工处理，扩展会先做一层清洗，保证能被标准 Cookie 解析器（`http.cookiejar` / `SimpleCookie`）直接消费：

| 规则 | 说明 |
|---|---|
| 丢弃空名片段 | 从 DevTools 复制时偶尔会混入 `=douyin.com` 这类无 name 片段，它会让下游解析报错 |
| 丢弃非法字符 | name 含空白/控制字符/引号/分号/逗号/等号，或 value 含空白/控制字符/引号/分号/逗号 |
| 丢弃已过期项 | `expirationDate` 早于当前时间 |
| 同名去重 | 非空值优先 → 过期更晚优先 → 完全相同则保留后写者（与浏览器语义一致） |
| 空值保留 | `name=` 不丢，避免被误判成「关键字段缺失」 |
| 不排序 | 保持 `getAll` 原序，便于与 DevTools 对照排查 |

### 未登录会被拦下

检测到登录态核心字段缺失时**不会写入剪贴板**，弹窗显示红色提示，并给出「仍要复制（不保证可用）」的兜底入口 —— 既能当场拦住"导出了一串没用的 Cookie"，又不会在平台改字段名时把你锁死。

| 平台 | 核心字段（缺失即拦截） |
|---|---|
| 抖音 | `sessionid` |
| 小红书 | `web_session` |
| B站 | `SESSDATA` |

### 「仅保留关键字段」开关

勾选后只导出白名单字段（串更短、泄露面更小），默认**不勾选**（全量导出）。

> ⚠️ 白名单来自前端展示的字段清单，**尚无采集器实证需求**。若未来采集接口需要白名单外的字段，开启本开关会导致 403 且难排查 —— 默认全量更安全。

## 注意事项

- Cookie 含登录态，**不要泄露、不要提交到公开仓库**。
- 部分平台 Cookie 会过期，弹窗会提示最早过期时间；采集失败重新复制一次即可。
- 仅对 `douyin.com` / `xiaohongshu.com` / `bilibili.com` 三个域名授权了读取权限（见 `manifest.json` 的 `host_permissions`）；如需扩展到其它站点，在 `host_permissions` 里追加对应域名后重新加载扩展。

## 已知限制

- **不合并父域 Cookie**：抖音的部分 Cookie 可能落在 `.toutiao.com` / `.bytedance.com` 等父域，本扩展不读取它们。刻意不加这些域名，是为了不让安装权限弹窗扩大；确有需要时在 `host_permissions` 追加后重新加载即可。
- **不做定时/批量**：必须人工在浏览器里点一下，无法无人值守。
- **不直接写入 VerdaAI**：只负责复制到剪贴板，粘贴与保存仍在设置页完成。
