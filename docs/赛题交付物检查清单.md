- ✅ 保存 PID 文件供 `stop.sh` 统一管理

**用法**：
```bash

./scripts/run-demo.sh --check      # 仅检查依赖，不启动
```

**影响**：评审方或新用户在没有百度 AK / LLM API Key 的情况下，可快速启动项目并演示完整功能链路，满足赛题"一键构建/自动化测试脚本"要求。
