## 2. 清洗管线（`clean` / `_dedupe` / `norm_name`）

百度地点检索（`place/v2/search`，关联 `scope=2、sort_name:distance`）原始返回 → 清洗：

1. **字段规范化**（`norm_name`）：统一全/半角、去首尾空白、折叠重复空格；
2. **地理合法校验**：必须有 `lng/lat`，剔除越界/wrong 类型；
3. **空间去重**（`_dedupe(radius=50m)`）：同一类别内，两 POI 距离 < 50m 判为同一设施（百度对同一实体常以多个 POI 返回，如"凯里老街菜市场"与"老街农贸市场"）；保留其一（去重半径 50m，覆盖地址精度与查询噪声）；
4. **类别归属**：每个类别用多关键词查全后合并清洗，重叠设施跨类别保留（例如"社区医院"同时命中医疗与三要素药店键的除外——三要素药店单独键控）。

```python
def clean(items, dedupe_radius_m=50.0):
    norm  → 过滤缺坐标 → 按名称+坐标聚簇 → 簇内保留首选
```

### 2.1 类别统计与耗时回填（`to_stats` / `backfill_nearest_minutes`）

- 对每类统计：检索总数、**圈内数量**、覆盖度。这一行的旧写法有**两处**口径已经换代、照着读会读错：
  - **圈内 = 可达区 `scope.reach_ring`，不是"15min 等时圈 Polygon"**。它随可达尺 `reach_full_min` 而变（**今天 20min**）。旧形参名 `iso15_ring` 承诺 15min、实收 20min、文档又写 15min ⇒ 三处不一致而没有任何一层能发现；现在圈从 `scope` 取，而 `scope` 的构造校验过环的 `minutes == caliber.reach_full_min`（尺名与真源见 `AGENTS.md` §7.1「可达尺」）。
  - **覆盖度的分子不是圈内点数**：`coverage = min(1, 门槛项数 / ideal_circle)`，门槛项数唯一出自 `required_count_from_points`（`cov-1` 口径）。`in_circle` 仍如实报点数，但它是"图上画了几颗"，**不进覆盖度**。
- 对每类圈内 POI 用 IDW 耗时场插值出 `min_minutes`（到该类**最近**设施耗时）与 `nearest_name`——供"可达性"评分与最近设施报告使用。

## 3. 服务盲区识别（`blindspot.py`）

### 3.1 判盲规则

以中心为原点、`study_radius_m=2500m` 研究域内铺 `BLIND_GRID_M=200m` 网格（奇数对称，中心格恰在原点）。对每个格：

- 以格心为圆心、`BLIND_RADIUS_M=1000m` 为半径；
- 若该圆内 **三要素任一（菜市场/药店/小学）为空** → 该格标记缺失（`miss_mask=True`）；
- 即"在这里住，**直线 1km** 内没有菜市场/药店/小学任意一种"。⚠️ 这句**不折成"走路几分钟"**：1km 是单独登记的政策量（`caliber.blind_radius_m`），与可达尺那把时间尺互不换算——"15 分钟 = 1 公里"这句国标没写过，我们也不这样推（完整理由见本文 §6 末条）。

```
miss(i,j) = ¬(∃ market) ∨ ¬(∃ pharmacy) ∨ ¬(∃ primary)
            其中 ∃ 表示 1km 圆内存在
```

实现用**局部米坐标预转**（三要素点一次性投影到局部平面，逐格向量化判定，避免每格重复球面计算）。

### 3.2 灰区聚合（连通域 → 盲区多边形）

- 对 `miss_mask` 做**连通域提取**（4-邻接），相邻缺失格聚合为同一灰区；
- 每个连通簇输出：盲区 `id`（`bs-N`）、中心点、缺失要素清单 `missing_facilities`、聚合后 `polygon`（GeoJSON，边缘闭合）、`radius_m=1000` 口径、以及该簇内**最近可及设施**（最近`facility/name/distance_m/direction`）——报告里展示"哪里缺什么、离它最近能去哪买/看/学"；
- 去重：同一缺失跨多次检索只出现一次。

### 3.3 盲区语义

盲区数与分布同时进入评分（惩罚项）与报告叙事（整改优先级），是"体检"最有信息量的输出之一。

样例读数（**只背 2026-09-19 那一批 live 实跑**：凯里 3 处、劲松 1 处，明细见 [真实社区对比测试报告.md](./真实社区对比测试报告.md) §5）：欠发达样区的灰区更连片，成熟城区多在边缘零星成块。两个别读错的点：

1. 那一批里"整片缺养老"**不是资源缺失**，是**检索面**未检出 —— 当时 `elderly` 名称词只有「养老院／日间照料中心」，社区级命名不在词内（10-03 取证改判并补词，仓内可见的那一步是提交 `e9fe6a8`；另见 §1.1 的真源指引）；
2. **当前出厂的两份演示夹具（`kaili.json` / `beijing-jinsong.json`）盲区数都是 0 处**，且可判定域只有 9/72、21/99 格 ⇒ 它们既不能当"有盲区"的样例、也不能反过来当"全圈无障碍"的证据。要看有台账的实跑件，用 `kaili-ev2.json`（判盲 8 格 / 1 处盲区）。

## 4. 综合评分（`scoring.py`，透明公式）

### 4.1 四维度加权

```
total = 0.40·coverage + 0.25·reachability + 0.20·diversity + 0.15·balance
```

| 维度 | 含义 | 计算 |
|---|---|---|
| `coverage` 覆盖 | 八类设施"够不够" | 各类 `min(1, 门槛项数 / ideal_circle)` 均值 ×100 —— `cov-1` 起分子**不是圈内点数**，唯一出自 `poi.required_count_from_points`（只有旧载荷退回点数） |
| `reachability` 可达 | 最近设施快不快 | 各类 `max(0, 1 − min_minutes/20)×100` 均值（20min 满分口径）。⚠️ `min_minutes` 为 `None` 的类别（圈内该类一个都没有）**整条不进平均** ⇒ 少掉的是 0 分项、这一维会被抬高，所以 `note` 必须说明，否则读起来像"修个 bug 把分修高了" |
| `diversity` 多样 | 多少类在圈内有设施 | `圈内有设施的类数 / 8 ×100`（判据是 `in_circle > 0`） |
| `balance` 均衡 | 最弱那一类有多弱 | `(1 − worst_gap) ×100`，而 `worst_gap = max(1 − min(1, coverage))` ⇒ 等价于**各类覆盖率里的最低值**。这里**不是标准差**：旧写法"100 − 标准差×100"与代码不符，而且它会把"一类极差、其余都好"和"八类都平庸"算成同一个数（`docs/真实社区对比测试报告.md` §4 那一行叫「短板（最弱类覆盖）」，与代码一致） |

单类别维度分 `_cat_score = 0.7×coverage + 0.3×reachability`（雷达/柱状图用）。

### 4.2 盲区惩罚

```
外推条数 = 实测盲区数 ÷ 判定覆盖率        # 覆盖率缺失 ⇒ 退回按条数计（不猜、不放大）
total −= min(12, (外推条数 − 1) × 4)     # 1 处不罚，2 处起每处 4 分，封顶 12 分
total = clamp(total, 0, 100)
```

外推（比率估计）纠正的是一条**反向激励**：证据面越小判出的盲区越少，只按条数扣分等于把"少采集"奖励成"高分"。⚠️ 它假定已判定面有代表性，而判不了的都是可达区外沿、恰恰更稀疏 ⇒ 该估计**系统性偏乐观**，所以它**只用于扣分**，绝不写进 `blindspot_count` 或盲区清单（清单严格证据有界，不伪造多边形）。判定覆盖率同时落 `confidence` + `evidence` 举证 —— 覆盖率低意味着"判不出盲区"不再等于"没有盲区"，分数必须为此付账。

### 4.3 可解释性

评分非黑盒：报告携带 `note`（各维度得分 + 盲区扣分明细）、`radar`（分类维度雷达）与 `bars`（覆盖值），演示可直接向评委解释每分来源。

## 6. 边界与局限（披露口径）

- 去重半径 50m、盲区网格 200m、1km 圆判盲均为**工程约定**，文档披露并在报告 `methodology` 注明，避免"黑盒"；
- POI 依赖百度地点库完整性：老小区空白角落可能漏采（欠发达样区尤甚），搜索关键词已多词查全缓解；
- **判盲半径 1km 与 15min 可达圈是两把独立的尺，不做换算**：1km 住在 `caliber.py` 的 `blind_radius_m`（单独登记的政策量，步行/骑行/驾车现同值），用在「三要素各自 1km 内都查不到 ⇒ 该格判盲」这一条上，半径越大越难判出盲区（少报优先，证据域外的格记"不确定"而不是"盲"）；
  15min 圈则由路网实测决定 —— 若按**口径表声明的** 80 m/min ÷ 绕行系数 1.3 推，理论直线半径 ≈923m；但 `rc-1` 从实测耗时场反标定出的常态绕行系数是**凯里 1.620 / 劲松 1.529**（文献 +14%≈1.14），按它们反算得 **741m / 785m**。当前出厂夹具里真跑实测的 15min 圈等面积半径是 **705m / 748m**（北京劲松那圈最大外接 941m，等面积到 20min 圈才 ≈1023m）⇒ 实测标定那条与真跑等面积只差约 **5%**（741 vs 705、785 vs 748），而**声明值那条差 +31% / +23%** —— 也就是说 **1.3 是声明、不是实测**，拿它做的推演只能当量级参考（三个数并列披露、不挑一个当唯一真值，见 `AGENTS.md` §7.1 第三把尺）。⇒ 1km **大于** 15min 圈，它是尺度上的放宽，不是"安全余量"；
- 外部依据只在国标的**逐要素**服务半径表里，不在时间层级上：TD/T 1062 表 A.1 给 15 分钟层级的社区卫生服务中心、门诊部、社区服务中心（街镇级）登记服务半径 1000m，而本项目盲区三要素对应的行是小学 500m、菜市场或生鲜超市 500m、药店（列在 5-10 分钟「社区商业网点」行）300m；
  该标准全文不出现"公里"，层级只按出行时间与行政边界定义（「15 分钟层级。宜基于街道社区、镇行政管理边界……确定社区生活圈范围」）⇒「15 分钟 = 1 公里」这句国标没写过，我们也不这样推。
