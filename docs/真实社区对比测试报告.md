# 真实社区对比测试报告（凯里老街 vs 北京劲松）

> 版本：v1.0（M5 · 真实百度 API 实跑，数据来源见文末复现步骤）
> 测试日期：2026-09-19 ｜ 数据模式：`data_mode=live`（真实批量算路 + 地点检索）
> 结论先行：**两个社区均为"中等偏弱"（58.5 / 56.6 分），且短板完全不同**——凯里缺养老设施，劲松缺菜市场；"城区越成熟生活圈越优"的直觉被真实数据部分推翻。

---

## 1. 测试目的与参数

验证"15 分钟生活圈智能体检"在真实地图开放能力下的可复现性、可信度与诊断价值，并把真实快照固化进内置演示（离线可复现同一批结果）。

| 参数 | 取值 |
|---|---|
| 中心点（BD-09） | 凯里老街 `[107.9758, 26.5734]`；北京劲松 `[116.4637, 39.8832]` |
| 研究范围 | 半径 2500m |
| 采样 | 标准档：粗网格 400m + 800–1600m 边界带极坐标加密，共 498 点/社区 |
| 测时 | 百度 `routematrix/v2/walking` 批量矩阵（25 点/块），块失败自动 `directionlite` 单点兜底 |
| 插值 | IDW k=8 近邻，等值线 marching-squares（连接中心连通域） |
| 设施 | 8 类民生 POI + 三要素（菜市场/药店/小学）1km 判盲 |

## 2. 等时圈对比（5/10/15/20 分钟面积，km²）

| 社区 | 5min | 10min | 15min | 20min |
|---|---|---|---|---|
| 凯里老街 | 0.06 | 0.42 | **1.36** | **2.74** |
| 北京劲松 | 0.06 | 0.33 | **1.26** | **3.23** |

- 15min 圈：凯里 1.36 > 劲松 1.26（相当）；
- 20min 圈：劲松 3.23 > 凯里 2.74——劲松周边路网延伸性更好，但 **15 分钟圈内设施密度反而更弱**（见 §3）。

## 4. 综合评分对比（0–100，口径：覆盖 40% / 可达 25% / 多样 20% / 短板 15% + 盲区惩罚）

| 维度 | 凯里老街 | 北京劲松 |
|---|---|---|
| 覆盖 | 87.5 | 75.0 |
| 可达 | 55.9 | 46.6 |
| 多样 | 87.5 | 75.0 |
| 短板（最弱类覆盖） | 0.0（养老 0） | 0.0（菜市场/养老 0） |
| 盲区惩罚 | −8.0（3 处） | 0（1 处，不罚） |
| **总分** | **58.5** | **56.6** |

- 凯里总分略高主因：**圈内设施覆盖更好**（医疗/教育/购物圈内多于劲松），即使盲区更多（3 vs 1）；
- 劲松失分主因：**菜市场整类圈内缺失**（覆盖维度直接拉低）——"成熟城区"的假想被数据纠正；
- 两社区短板分均为 0：最弱民生类别（养老）完全缺失是共性结构性问题（与"养老"POI 本就稀缺有关，见 §6 局限）。

## 5. 盲区对比（1km 判盲，200m 网格，灰区聚合）

| 社区 | 盲区数 | 明细 |
|---|---|---|
| 凯里老街 | 3 | bs-1 三缺全缺 · bs-2 缺药店 · bs-3 三缺全缺 |
| 北京劲松 | 1 | bs-1 三缺全缺（菜市场缺位主导） |

- 凯里盲区呈**多点散布 + 连片缺失**：老街片区外围 1km 内菜市场/药店/小学同时缺（符合欠发达样区预期）；
- 劲松盲区仅 1 块但"三缺全缺"：位于 15min 圈覆盖边界，核心症结是圈内菜市场为零——改善优先级最高（菜市场/菜店布点可解）。

## 6. 差异归因与启示

1. **真实数据推翻手绘先验**：早期手绘 fixture 预设"劲松 86（成熟）> 凯里 65（欠发达）"；真实路网测时下两者 58.5 ≈ 56.6、且短版不同。说明"体检"必须依赖实测，不能按印象打分；
2. **"城区成熟"≠"步行圈内设施充足"**：劲松 20min 圈大（3.23 km²）但 15min 圈内购物/菜市场密度反而不如凯里——可达圈扩展 > 设施布局密度；
3. **共性短板——养老**：两社区 15min 圈内养老设施均为 0，反映养老 POI 本身稀疏与生活圈配套的普遍缺口，可作为报告"整改建议"主线；
4. **盲区口径（1km）从严且接受度好**：劲松 1 处、凯里 3 处，与直觉一致，差异化明显。

## 7. 局限与披露

- 采样 + IDW 插值是"路网近似"，精度依赖百度路网质量与采样密度（标准档 498 点、边界带加密缓解）；
- POI 依赖地点库完整性与关键词查全（多词策略已尽力，漏采在欠发达角落仍可能）；
- 等时圈与 1km 判盲的换算采用 75m/min 步行基准（安全余量）；
- 评分公式与参数（权重/惩罚/短板分）全链路披露，见 [多源POI数据清洗与服务盲区识别算法.md](./多源POI数据清洗与服务盲区识别算法.md) 与 [地图API调用策略与等时圈算法设计.md](./地图API调用策略与等时圈算法设计.md)。
